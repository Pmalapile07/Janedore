# JANEDORE app concept

A standalone, mobile-first visual prototype for exploring the future JANEDORE shopping app interface.

- This is a design prototype only. It does not connect to Firebase, customer accounts, live products, checkout, or Capacitor.
- It lives on the `app-design-prototype` branch and does not change the live website's `main` branch.
- Product names, prices, brands, and photography are illustrative placeholders.
- The prototype uses the existing JANEDORE wordmark direction and a clean black-and-white interface.

Open `index.html` in a browser or serve this folder as a static site to preview it.
